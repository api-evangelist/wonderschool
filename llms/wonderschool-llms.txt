# Wonderschool

> Wonderschool is a child care platform that helps families find licensed care and helps providers start, operate, and grow child care programs. It also delivers software and services to government agencies (licensing, subsidy management, enrollment coordination, substitute-teacher pools) and to employers offering child care benefits. As of this writing Wonderschool does not publish a public developer API, SDKs, or webhooks; this file is generated from the API Evangelist catalog profile.
